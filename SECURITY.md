# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability").

Include the affected package and version, what an attacker can do, and steps to reproduce. You will get an acknowledgement within a few days. Fixes are released as a new patch version and the advisory is published once a fix is available.

## Supported versions

The latest 1.x release.

## Scope

The packages in this repository. Deployments of the CSuit products are out of scope here.
